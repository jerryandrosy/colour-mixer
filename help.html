How to Use the Website

  1. Select two colours from the dropdown menus.
  2. Click the Mix Colours button.
  3. The new colour name will appear below.
  4. The preview box will display the mixed colour.
  5. The recent mixes section will show your last few mixes.

Supported Colours

  • Red
  • Blue
  • Yellow
  • Black
  • White

Example Mixes

  • Red + Blue = Purple
  • Yellow + Blue = Green
  • Red + Black = Maroon
  • Blue + White = Light Blue
  • White + Black = Gray
