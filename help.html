Need help? This page explains how to use the Colour Mixer.

How the Website Works

  1. Choose your first colour from the dropdown menu.
  2. Choose your second colour from the next dropdown menu.
  3. Click the Mix Colours button.
  4. The website will show the mixed colour name and display it in the preview box.
  5. Your latest mixes will also appear in the recent mixes section.

Supported Colours

At the moment, the website supports a small set of basic colours:

  • 🔴 Red
  • 🔵 Blue
  • 🟡 Yellow
  • ⚫ Black
  • ⚪ White

Example Mixes

Here are a few mixes the website can currently create:

  • Red + Blue = Purple
  • Yellow + Blue = Green
  • Red + Black = Maroon
  • Blue + White = Light Blue
  • White + Black = Grey
